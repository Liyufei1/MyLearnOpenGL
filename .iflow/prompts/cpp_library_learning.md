## 库概述
- **库名称**：GLM (OpenGL Mathematics)
- **版本**：0.9.9+
- **官方网站**：https://github.com/g-truc/glm
- **一句话描述**：基于 GLSL 规范的 C++ 数学库，专为 OpenGL 设计

## 核心概念

### 设计思想
GLM 的设计理念是模仿 GLSL 的数学类型和函数，使 C++ 代码与着色器代码保持一致，降低学习成本。

### 关键术语
- **向量（Vector）**：表示方向或位置，如 `vec3`、`vec4`
- **矩阵（Matrix）**：用于变换，如 `mat4`
- **四元数（Quaternion）**：用于旋转，如 `quat`
- **Swizzling**：向量分量重排，如 `vec3(1,2,3).xyz()`

### 主要特性
- Header-only 库，无需编译
- 与 GLSL 语法高度兼容
- 支持 SSE/AVX 优化
- 丰富的数学运算函数

## 主要类/接口

### 核心类

#### vec3
- **职责**：3D 向量，表示位置、方向或颜色
- **主要方法**：
  - `length()` - 计算向量长度
  - `normalize()` - 归一化
  - `dot()` - 点积
  - `cross()` - 叉积

#### mat4
- **职责**：4x4 矩阵，用于 3D 变换
- **主要方法**：
  - `translate()` - 平移变换
  - `rotate()` - 旋转变换
  - `scale()` - 缩放变换
  - `inverse()` - 矩阵求逆

### 关键接口
- `glm::radians()` - 角度转弧度
- `glm::degrees()` - 弧度转角度
- `glm::lookAt()` - 创建视图矩阵
- `glm::perspective()` - 创建投影矩阵

## 典型使用模式

### 初始化流程
```cpp
#include <glm/glm.hpp>
#include <glm/gtc/matrix_transform.hpp>
#include <glm/gtc/type_ptr.hpp>

// GLM 是 header-only，无需初始化
```

### 基础用法
```cpp
// 创建向量
glm::vec3 position(1.0f, 2.0f, 3.0f);
glm::vec3 direction = glm::normalize(position);

// 向量运算
float distance = glm::length(position);
glm::vec3 cross = glm::cross(position, direction);
float dot = glm::dot(position, direction);
```

### 进阶用法
```cpp
// 变换矩阵
glm::mat4 model = glm::mat4(1.0f);
model = glm::translate(model, glm::vec3(0.0f, 0.0f, -5.0f));
model = glm::rotate(model, glm::radians(45.0f), glm::vec3(0.0f, 1.0f, 0.0f));

// 传递给着色器
glUniformMatrix4fv(modelLoc, 1, GL_FALSE, glm::value_ptr(model));
```

### 资源管理
- GLM 是纯数学库，不涉及资源管理
- 所有对象都在栈上创建，无需手动释放

### 错误处理
- GLM 不使用异常，通过 assert 检查错误
- 调试模式下启用 GLM_FORCE_MESSAGES

## 与本项目集成要点

### 集成步骤
1. 将 GLM 头文件复制到 `include/glm/` 目录
2. 在代码中包含需要的头文件
3. 无需链接额外的库

### 配置要求
- 编译选项：`-std=c++17`
- 链接库：无
- 头文件路径：`include/glm/`

### 常见陷阱
- ⚠️ 矩阵乘法顺序：GLM 使用列主序，注意 `model * view * projection` 的顺序
- ⚠️ 角度单位：GLM 使用弧度，需要用 `glm::radians()` 转换
- ⚠️ 矩阵初始化：`glm::mat4(1.0f)` 创建单位矩阵

### 性能建议
- 使用 `glm::simd` 版本获得 SIMD 优化
- 避免频繁创建临时矩阵对象
- 使用引用传递大型矩阵和向量
